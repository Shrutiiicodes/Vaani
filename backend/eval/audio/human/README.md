# Recordings to make

Record each sentence below on a phone, the way a customer would say it at a counter. A normal room with some background noise is fine. Save each clip in this folder with the exact filename shown.

Any format works: .m4a (iPhone Voice Memos), .mp3, .wav, .ogg or .webm. Keep the language and number, and change only the extension to match your file.

Then run `python backend/eval/run_stt_eval.py --hint`. Human clips are found automatically and reported separately from the synthetic ones.
